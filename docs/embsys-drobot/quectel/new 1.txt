=================================
By default, Quectel modems like RM530N can present different USB modes, called compositions, which define which functions are available over USB — e.g.:

Function			Purpose
AT port (ttyUSB)	Control modem
QMI/MBIM			Provide raw IP access to Linux
ECM/RNDIS			Virtual Ethernet interface
GPS, Audio, etc.	Optional services

Right now, your modem is in AT-only composition, so Linux doesn't see a network interface.


🔧 What we’ll do:

	Use AT command to switch USB mode to QMI or MBIM		
	Reboot modem
	Use ModemManager or qmicli to bring up data connection



Step 1: check current USB composition:
	AT+QCFG="usbnet"
	
	Expected should be: +QCFG: "usbnet",0  [0 = AT-only mode (your current mode)]
	
		0 = AT-only mode (your current mode)
		1 = ECM (USB network, like usb0)
		2 = RNDIS (used in Windows mostly)
		3 = MBIM (used by ModemManager, best for Linux)
		5 = QMI (also great for Linux)

	HOWEVER (BUT...BUT)
	when I send "AT+QCFG="usbnet"" I get -QCFG: "usbnet",2 OK response...
	
	Chatgpt: This means your Quectel modem is currently in:
	🔌 RNDIS mode — a virtual Ethernet interface, mainly used by Windows systems.
	
	❌ Why RNDIS is a Problem on Raspberry Pi (Linux)
	Linux has poor support for RNDIS modems, especially for managing them automatically.
	You likely won’t see a usb0 or eth1 interface.
	No clean integration with ModemManager or NetworkManager.

	✅ What You Should Do: Switch to QMI or MBIM Mode

	We want to switch to mode 3 (MBIM) or mode 5 (QMI).
	
	To switch to QMI (recommended):
		AT+QCFG="usbnet",5   (I found error...perhaps this mode not supported in firmware)
	Or for MBIM (also good):
		AT+QCFG="usbnet",3
		
	Then reboot modem:
		AT+CFUN=1,1

	After reboot type "AT+QCFG="usbnet" and this time mode should be 3 
	(so the modem is configured in MBIM mode...usbnet=3)

	sudo systemctl enable NetworkManager

Step 3: Confirm modem detection
	mmcli -L
	
	mmcli -m 0  (for detailed information)
	
	mmcli -i 0  (information is coming from the sim..and not from the network)

Step 4: Enable the modem and register on the network


sudo mmcli -m 0 --enable
sudo mmcli -m 0 --simple-connect
sudo mmcli -m 0 --connect
