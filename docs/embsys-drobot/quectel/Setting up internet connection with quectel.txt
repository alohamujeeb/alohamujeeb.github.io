Here’s a step-by-step guide to set up the data connection using AT commands:


================================================================================
Step 1: Set the APN (Access Point Name)

AT+QICSGP=1,1,"your_apn","","",1

Replace "your_apn" with the APN from your SIM provider (e.g., internet, wap, etc.).
The parameters mean:
    1 → PDP context ID
    1 → Activate the context
    "" → Username (if any)
    "" → Password (if any)
    1 → Authentication type (1 = PAP, 0 = None, 2 = CHAP)
	
	Example:
	AT+QICSGP=1,1,"internet","","",1


OR Check APN Automatically (if supported)
AT+QICSGP=1,1

If you do not know APN, then go to step 2 and try your luck
(I got error with M1)

================================================================================
Step 2: try activating PDP context without setting APN:
AT+QIACT=1

(If this works, you’re lucky and the module uses the default APN.)
======================
Step 3: Check IP address
AT+QIACT?

+QIACT: 1,1,1,"10.35,23,61"
OK

================================================================================
Step 4: Open a network socket (Optional)

AT+QIOPEN=1,0,"TCP","www.google.com",80,0,1
	1 → context ID
	0 → connection ID
	"TCP" → protocol
	"www.google.com" → remote host
	80 → remote port
	0 → local port (0 means auto)
	1 → asynchronous mode
	
Response:
	OK
	+QIOPEN: 0,0
================================================================================
Step 5: Check connection status

AT+QISTATE=1,0

It shows:

+AISTATE: 0, "TCP", "142.251.12.103", 80, 16622,2,1,0,1, "usbat"
OK
================================================================================

Purpose of Minicom
Exactly — minicom is primarily a tool for sending AT commands to your modem. Now, about the broader purpose of AT commands:

Purpose	Explanation
1) Testing the modem hardware	Check if the modem is responsive, get info about model, firmware version (ATI command)
2) SIM card management	Check SIM status, enter PIN code, check network registration, SIM unlocking (AT+CPIN, AT+COPS)
3) Network registration and signal	Check if modem is registered on network, get signal strength (AT+CREG?, AT+CSQ)
4) Data connection setup	Configure PDP context, APN, activate data connection (AT+QICSGP, AT+QIACT)
5) SMS management	Send, receive, and manage SMS messages (AT+CMGS, AT+CMGR)
6) Voice call control	Make and receive calls (ATD, ATA, ATH)
7) Network diagnostics and control	Run ping tests if supported, check operator info, control radio settings
8) Firmware update and configuration	Some modems allow advanced control for firmware upgrades, device configuration
9) Custom vendor-specific commands	Extended features, proprietary commands for special modem functions


- AT commands are the universal language to interact with and control cellular modems.
- Minicom lets you manually send these commands for setup, troubleshooting, and control.
- Once set up, other software (ModemManager, PPP, etc.) automates these commands.

After AT command setup and testing:
Now, time time for full internet access via a proper network interface on your Raspberry Pi using your RM530N-GL 5G modem.

By the end of this setup, your Raspberry Pi will:

    Automatically detect the 5G modem over USB
    Connect to your mobile network (using your SIM)
    Expose a network interface (wwan0 or similar)
    Give you internet access like Wi-Fi or Ethernet

We'll do this with:
    ✅ ModemManager + NetworkManager — the modern, clean, system-integrated way.

🔧 Step 1: Close minicom
	CTRL + A, then press Z, then press X


==========================================
📦 Step 2: Install ModemManager & NetworkManager
	``` bash
	sudo apt update && sudo apt upgrade -you
	```
	
	``` bash
	sudo apt install -y \
	modemmanager \
	libqmi-utils \
	libmbim-utils \
	usb-modeswitch \
	network-manager
	```
	(sudo reboot) after that

Step 3: Start and Enable Services
	sudo systemctl enable --now ModemManager
	sudo systemctl enable --now NetworkManager

🔍 Step 4: Check if Modem is Detected
	mmcli -L

	You shouold see an ouptu like:
	/org/freedesktop/ModemManager1/Modem/0 [Quectel] RM530N-GL

🔎 Step 5: Get detailed modem info
	mmcli -m 0
	
	This will show:
		Signal strength
		SIM status
		Operator name
		Modem state
		
📶 Step 6: Enable the Modem
	sudo mmcli -m 0 -e

	"successfully enabled the modem"

🌐 Step 7: Add a Mobile Connection
	sudo nmcli connection add type gsm ifname "*" con-name my-5g apn internet
	
	connection 'my-5g' (xxxxxxxxxxxxx) successfully added
	

🚀 Step 8: Start the Connection
	sudo nmcli connection up my-5g
