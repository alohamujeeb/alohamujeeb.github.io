# 01. Getting started


---
## 1. VueJS is simple

- Vue.js is a **progressive** JavaScript framework, which means you can start small.

- You can add it to just a part of a page and gradually scale up to a full-featured application.

- This flexibility sets it apart from more **monolithic** frameworks like **Angular** or **React**, which often require more setup and architectural decisions upfront.
