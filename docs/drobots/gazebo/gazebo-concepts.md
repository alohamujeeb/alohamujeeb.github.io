## Gazebo Concepts


1a). Server vs Client parts
1b). Simulation Environment

A 3D physics-based world where robots, sensors, and objects interact realistically.

2. World

The overall simulation scene definition, including terrain, lighting, physics, and objects.

3. Models

Individual entities in the simulation such as robots, obstacles, and props.

4. Physics Engine

Core system that simulates motion, collisions, gravity, and real-world dynamics.

5. Sensors

Virtual sensors that generate simulated data like cameras, LiDAR, IMU, and GPS.

6. Plugins

Extend Gazebo functionality by adding custom behaviors, control logic, or integrations.

7. Links & Joints

Building blocks of models that define rigid bodies (links) and their connections (joints).

8. URDF / SDF Support

Formats used to define robot models (URDF) and full simulation worlds (SDF).

9. Topics (ROS / Transport)

Communication channels used to stream sensor data and control commands.

10. GUI / Visualization Interface

Interactive interface for viewing, editing, and controlling the simulation in real time.

11. Visualization vs Simulation

Separation between visual rendering of the environment and the underlying physics-based simulation that drives robot and object behavior.
