# **Golang Programming**

Go language is developed by Google and this site is designed to contains tutorials to quickly learn basic skills and many application samples.

- Open source and cross-platform (Linux, Windows, Mac)
- Easy to learn (like Python)
- Fast compilation (hence suitable for huge systems where compilation is done very frequently)
- Fast execution (like C/C++)
- An excellent language for web backbends
- Concurrency for heavy multitasking
- Contains packages for web servers, I/O, cryptography, and more
- Development tools:  Includes go fmt, go test, go build, and more for streamlined development.

## What it is not
Go is primary created for web backends with heavey concurrency support. 
It may NOT be the best option for system programming for which C/C++ and Rust are more appropriate options.
