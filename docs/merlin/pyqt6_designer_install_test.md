## PyQt6 installation with designer
```

1) To install
	pip install PyQt6
	pip install pyqt6-tools


2)  To launch designer and generate .ui
pyqt6-tools designer
or
designer  (sometimes this works)


3) To compile .ui to .py
pyuic6 test.ui -o test_ui.py


4) to run the generated app
	test_ui.py



```
